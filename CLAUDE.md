# Правила выполнения лабораторных работ

## Процесс
1. Новое задание лежит в `inbox/` (PDF или DOC/DOCX).
2. Прочитать задание полностью, выписать требования и правила оформления.
3. Создать папку `labs/labNN/` со структурой:
   - `task.md` — текст задания (кратко, по пунктам)
   - `src/` — код решения
   - `report.md` — отчёт (цель, ход работы, результаты, выводы)
4. Выполнить работу, запустить и проверить результат.
5. Оригинал задания перенести из `inbox/` в `labs/labNN/`.
