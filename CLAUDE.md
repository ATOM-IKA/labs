# Правила выполнения лабораторных работ

## Процесс
1. Новое задание лежит в `inbox/` (PDF или DOC/DOCX).
2. Прочитать задание полностью, выписать требования и правила оформления.
3. Создать папку `labs/labNN/` со структурой:
   - `task.md` — текст задания (кратко, по пунктам)
   - `src/` — код решения
   - `report.md` — отчёт (цель, ход работы, результаты, выводы)
4. Выполнить работу, запустить и проверить результат.
5. Оригинал задания перенести из `inbox/` в `labs/labNN/`.

## Оформление отчёта
- Формат отчёта: `.docx`.
- Образец: `inbox/LR1-2_KucherUD_31ISIP.docx` (лабораторная работа №1). Новые отчёты делать по нему.
- **На каждом листе обязательна рамка** с основной надписью (штамп внизу). Рамка и штамп лежат в колонтитулах образца (`word/header1.xml`, `word/footer1.xml`, с картинками `media/image1-2.jpeg`), поэтому отчёт строить на копии образца: сохранить колонтитулы, стили и параметры страницы, заменить только тело документа и данные в штампе (название работы, номер листа, ФИО).
- Параметры страницы из образца: A4, поля 2 см (1134 twips) со всех сторон, нумерация листов в штампе.
- Структура образца: заголовок «Лабораторная работа №N», тема, нумерованные разделы (1., 1.1.), таблицы, в конце «Вывод».
- Перед сдачей проверить, что рамка есть на каждой странице, включая последнюю.

## Инструменты и как собирать отчёты
- Генератор docx по образцу: `tools/make_docx.py` (рамка и штамп берутся из образца). Пример использования: `labs/lab6/build_report.py`.
- Проверка рамки: `soffice --headless --convert-to pdf файл.docx`, затем `pdftoppm -png` и посмотреть страницы.
- Результаты тестов должны быть реальными: тесты запускать по-настоящему (программа, JMeter на собственном локальном сервере), а не придумывать цифры.
- Тестировщик/автор в отчётах: Кучер У.Д. (вариант лабы 6: №13, программа расчёта площади помещения).

## Лекции и другие материалы
- Рамка нужна только в лабораторных работах. Лекции и прочие документы делать без рамки: `build(blocks, путь, frame=False)`.
- Лекции лежат в `lectures/`. Стиль: академический, ключевые моменты выделены жирным, без разговорных оборотов и «воды».
